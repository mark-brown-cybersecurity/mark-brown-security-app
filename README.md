# Mark Brown - Security Contracting & Portfolio Web App

This is a complete, downloadable Python web application built using **Streamlit**. It serves as an interactive professional portfolio, verified credentials index, and contract/subcontract submission portal for Mark Brown (Independent Security Operations Supervisor & Consultant).

## How to Run Locally

1. Install Python 3.8 or higher.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   streamlit run app.py
   ```

## Features
- **Interactive Sidebar Navigation:** Switch between Overview, Credentials Index, Active Contracts, and Inquiries.
- **Verified Credentials Table:** Displays PI license, armed guard license, CCW, cannabis health license, and degrees.
- **Contract Board:** Lists high-paying security and supervisory positions.
- **Inquiry Portal:** Allows companies to submit subcontract and placement requests directly.
